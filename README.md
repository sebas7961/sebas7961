### How I work

**Measure before fixing.** At EsSalud everyone agreed the paperwork was slow and nobody
could say where. I built the thing that measures it first. The bottleneck turned out not
to be where people assumed.

**Hardware sets limits software cannot argue with.** On HeartAlarm the weak point was the
pulse sensor, not the code. Knowing which layer is failing saves weeks of optimizing the
wrong one.

**Shipped beats clever.** A prototype that runs on a real server and gets used is worth
more than an elegant repo nobody opens.

**Adoption is part of the build.** I train the people who will use what I made. If it
needs me to keep working, I did half the job.
